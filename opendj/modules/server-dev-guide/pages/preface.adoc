== Preface

This guide covers LDAP and REST clients, directory data, and server plugins. For a Java client example, see xref:chap-ldap-sdk.adoc#chap-ldap-sdk[Developing Java LDAP Clients].

The examples assume familiarity with LDAP and command-line tools. The REST examples also use HTTP and JSON. If you need a server, see the xref:install-guide:index.adoc[Installation Guide].
